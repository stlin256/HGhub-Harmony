# HGhub Harmony v2.2.3

这次更新继续围绕播放体验、起播稳定性和日常使用细节做打磨。

## 播放体验

- 新增下一集与上下滑窗口预加载，优先缓存开头内容，缩短切集等待；
- 优化起播画幅策略：首次拿到视频尺寸立即定位，减少拉伸和二次校正；
- 修复 seek 后偶发自动暂停的问题；
- 修复播放器内部重载后误暂停的问题；
- 修复长按倍速时偶发跳回首个视频的问题；
- 完善后台播放与系统媒体会话：通知栏/锁屏可显示播放状态、时长和进度。

## AI 超分

- 优化 AI 超分逻辑：支持设备按需启用系统原生超分，不支持设备自动降级，避免反复重载和起播卡顿。

## 稳定性

- 优化播放器释放与会话生命周期，减少切换页面后的残留状态；
- 修复不支持能力设备上的重复重载问题；
- 清理未使用的配置项，降低配置歧义。

## 功能改进

- 分享链接与剪贴板域名回退逻辑修复：当前线路不可用时自动回退到可用地址；
- 推荐排序信号刷新链路修复，收藏/点击/快速划走后的排序更符合当前行为；
- 完善版本更新提示流程。

## 其他

- 修复若干播放页拆分后的回归问题；
- 保持 2.2.2 的界面与交互方式不变。

## 兼容性

- 适用 HarmonyOS NEXT；
- 旧版本升级不会清除本地收藏、历史与偏好设置。
