# v2.2.0 鸿蒙原生HGhub · 体验打磨

这次更新没有把重点放在堆功能，而是把每天都会用到的体验重新捋了一遍：**打开更快、切换更顺、播放更听话、线路更稳**，桌面也终于有了能用的卡片。

## 用起来更顺手

- 整个 App 的动画节奏统一：页面切换、列表刷新、加载出现、弹窗开合、按钮按压都按同一套节奏来，操作更跟手、少跳变、不闪白；
- 首页、搜索、分类、榜单、吃瓜、专题、关注、用户、详情等页面统一「骨架 → 内容」柔和过渡，刷新和换一批不再整页重闪；
- 收藏 / 历史切换保留滚动位置，再点当前 Tab 可回顶；「我的」大标题随滚动自然收起；
- 深浅色启动不再先闪深色，深色下系统导航栏不再发白；弹窗统一为应用内样式；
- 设置新增「减少动态效果」。

## 播放器更听话

- 画质一键切换并保留进度，默认优先高清，无高清源自动回退；
- 片尾自动续播更准确，拖动进度显示「正在跳转…」，不误触按钮、不误跳集；
- 起播网络抖动分级重试，减少黑屏/卡死；
- 上下滑切剧更稳；画中画、锁屏/控制中心控制、投播、跨设备接续。

## 线路和网络更稳

- 启动优先上次可用线路，失败自动重试/换线；线路面板打开即有缓存，延迟边测边显示；
- 多源加速默认开启，网络波动时自动从多条线路取最快响应；网络正常不额外请求；
- 播放中线路巡检，手动选线增加冷却避免误切。

## 打开更快、内容更全

- 启动预载榜单、吃瓜、专题、频道、热搜首屏；我的收藏/历史打开即见；
- 收藏/历史支持无限滚动，翻页去重；
- 新增专题合集、实时热搜、关注流、用户主页；搜索支持视频与吃瓜内容；
- 新增中英文基础文案、无障碍朗读优化。

## 桌面卡片（新）

- 2×2 继续观看：最新观看剧集大封面 + 顶部「继续观看」，点击回到上次进度；
- 2×4 收藏影视架：最多 4 张收藏封面，点封面直达对应剧集；本地和登录后的收藏都显示，无封面用占位卡；
- 封面使用高清快照；冷启动、收藏/取消收藏、切下一个视频后主动刷新；
- 旧版卡片请长按移除后重新添加一次，才能拿到新尺寸与封面。

## 平板 / 大屏

- 默认全宽多列瀑布流，打开内容时按需进入平行视窗，进出有动画；播放器在分栏内可一键全屏；
- 深色模式系统导航栏跟随主题；
- 开发者没有平板设备，平板/大屏问题欢迎通过 Issue 反馈；每个版本更新后首次启动会提示一次。

## 其他

- 设置新增：减少动态效果、优先高清、多源加速；「关于」显示真实安装包版本；本地崩溃日志入口；
- 修复启动偶发崩溃、点赞/收藏失败回滚错位、进度条拖动被打断、清理缓存后占用回填等问题；
- **AI 超分说明**：设置开关与播放页提示仅为体验保留；实际系统超分因部分机型画面崩坏已暂时关闭，当前不会真正进行超分；
- 匿名统计新增系统环境维度（API 版本、设备类型、厂商、屏幕等），仅用于客户端兼容性分析，不含个人数据。

## 安装

- HarmonyOS 7（API 26）设备安装 `.hap`；当前为测试签名包，仅限已授权设备。
