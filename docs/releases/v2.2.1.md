# v2.2.1 鸿蒙原生黄果短剧

这次更新继续围绕日常体验打磨：打开更稳、播放更顺、列表和桌面卡片更稳定，同时修复了近期反馈的几处问题。

## 用起来更顺

- 修复部分页面底部不沉浸、系统栏颜色不一致的问题；
- 列表、收藏与历史切换更顺滑，减少刷新时的闪动与跳动；
- 桌面卡片继续优化：继续观看大封面、收藏影视架，点击可直达剧集。

## 播放体验

- 修复部分场景播放卡在加载、进度不恢复的问题；
- 拖动进度、切集、切换画质的反馈更稳定；
- AI 超分：调用鸿蒙系统原生超分能力，根据设备与内容自动启用，在支持的机型上提升画面清晰度。

## 更新检查

- “检查更新”更稳定：有可用版本时展示版本号与下载地址，地址缺省时打开 Release 页。

## 稳定性

- 修复播放、收藏、历史等场景的若干异常与回滚问题；
- 优化启动和列表加载的稳定性。
